# 🌌 SWAPI Client (Работа с API «Звёздных войн»)

Этот проект представляет собой Python-клиент для взаимодействия с открытым API «Звёздных войн» (SWAPI). Программа запрашивает данные о различных категориях (люди, планеты, корабли и т.д.) и сохраняет их в локальные файлы для дальнейшего использования.

## 🎯 О проекте
В ходе выполнения задания я реализовала объектно-ориентированную структуру для работы с внешним API:
* Создан базовый класс `APIRequester` для выполнения HTTP-запросов и централизованной обработки сетевых ошибок (ConnectionError, HTTPError).
* Создан дочерний класс `SWRequester`, который наследует логику запросов и адаптирован под специфику SWAPI.
* Реализовано автоматическое скачивание всех доступных категорий данных и сохранение их в отдельные текстовые файлы в папке `data/`.

*Примечание: тесты для проверки этого кода были предоставлены образовательной платформой и не включены в данный репозиторий.*

## 🛠 Технологии и инструменты
* **Python 3**
* **Библиотека `requests`** — для выполнения HTTP-запросов к API.
* **Модуль `os`** — для создания директорий и работы с путями файловой системы.
* **Модуль `json`** — для работы с JSON-ответами от сервера.
* **ООП** — наследование, инкапсуляция, обработка исключений.
